## О проекте

В репозитории представлена курсовая работа по дисциплине «Управление данными». Выполнено проектирование и разработка базы данных для автоматизации деятельности ветеринарной клиники, а также реализовано клиентское приложение для взаимодействия с БД.

**Предметная область:** деятельность ветеринарной клиники (диагностика, лечение, послеоперационный уход, учёт клиентов и пациентов, складской учёт медикаментов).  
**Цель работы:** разработка и внедрение базы данных, обеспечивающей упрощение учёта, контроль всех этапов процессов и повышение эффективности работы организации.

## Функциональные возможности

### Учёт клиентов
- Просмотр клиентской базы.
- Добавление новых клиентов с проверкой уникальности ФИО, телефона, email и адреса.
- Обновление данных существующих клиентов.

### Учёт сотрудников
- Просмотр базы сотрудников с сортировкой и поиском.
- Добавление новых сотрудников с проверкой возраста (18+), уникальности паспортных данных, email и телефона.
- Обновление данных сотрудников.

### Управление графиками
- Просмотр всех графиков работы.
- Добавление, обновление и удаление графиков.
- Проверка корректности формата времени (HH:MM-HH:MM или NULL).

### Работа с питомцами
- Просмотр базы питомцев с ФИО владельцев.
- Добавление новых питомцев.
- Обновление возраста питомца.

### Проведение приёмов
- Просмотр информации о приёмах и услугах.
- Добавление приёмов с проверкой: время в будущем, в рабочие часы, без пересечений.
- Обновление комментария к приёму (не позднее 24 часов).
- Удаление приёмов и услуг.

### Складской учёт
- Просмотр складских операций.
- Проведение операций: выдача, списание, получение.
- Контроль остатков медикаментов.
- Управление справочником медикаментов.

## Структура базы данных

База данных включает **9 связанных таблиц**:

| Таблица | Назначение |
|---|---|
| **Клиент** | Данные владельцев животных (ФИО, телефон, email, адрес) |
| **Сотрудник** | Информация о работниках (ФИО, должность, паспорт, график) |
| **Питомец** | Данные пациентов клиники (кличка, порода, окрас, пол, возраст) |
| **Приём** | Записи о посещениях (дата, время, сотрудник, питомец, комментарий) |
| **Услуга** | Справочник услуг клиники |
| **УслугаПриёма** | Связь многие-ко-многим между приёмами и услугами |
| **СкладскаяОперация** | Операции по движению медикаментов |
| **Медикамент** | Справочник медикаментов (наименование, стоимость, срок годности, количество) |
| **График** | Расписание работы сотрудников по дням недели |

### Логические связи

```text
Клиент ──1:M── Питомец
Сотрудник ──1:M── Приём
Питомец ──1:M── Приём
График ──1:M── Сотрудник
Приём ──M:N── Услуга (через УслугаПриёма)
Медикамент ──1:M── СкладскаяОперация
Сотрудник ──1:M── СкладскаяОперация
Приём ──1:M── СкладскаяОперация
```

### Представления (Views)

- `Питомцы_с_ФИО` — информация о питомцах с ФИО владельцев.
- `Представление_СкладскаяОперация` — данные о складских операциях с ФИО сотрудников и наименованиями медикаментов.
- `ПолнаяИнформацияОПриемах` — приёмы с ФИО сотрудника, кличкой питомца, ФИО клиента и услугами.
- `V_Ветеринары_График` — график работы ветеринаров.
- `СотрудникиСкладаСГрафиком` — график работы сотрудников склада.

### Хранимые процедуры (Stored Procedures)

- `AddClient`, `UpdateClient` — добавление и обновление клиентов.
- `AddSort`, `UpdateSortByFIO` — добавление и обновление сотрудников.
- `ДобавитьПитомца`, `ОбновитьВозрастПитомца` — работа с питомцами.
- `ДобавитьМедикамент`, `ОбновитьМедикамент` — управление медикаментами.
- `ДобавитьПриёмИУслугу`, `ОбновитьКомментарийПриёма`, `УдалитьПриём`, `УдалитьУслугуПриёма` — работа с приёмами.
- `ДобавитьСкладскуюОперацию` — проведение складских операций.
- `ДобавитьГрафик`, `ОбновитьГрафик`, `УдалитьГрафик` — управление графиками.
- `ДобавитьУслугу` — добавление услуг.

Все процедуры реализуют комплексную проверку бизнес-правил и возвращают информативные сообщения об ошибках.

## Бизнес-правила

В базе данных реализованы следующие ограничения предметной области:

- Сотрудник должен быть старше 18 лет, иметь уникальные паспортные данные, email и телефон.
- Медикамент не может быть выдан, если его количество на складе меньше требуемого.
- Приём должен быть назначен в соответствии с графиком работы сотрудника.
- Запись на приём — не позднее чем за 24 часа до назначенного времени.
- Дата приёма не может быть ранее текущей.
- Количество медикаментов не может быть отрицательным.
- Приёмы не пересекаются для одного врача или питомца.
- ФИО, телефон, email и адрес клиентов должны быть уникальны.
- Изменение комментария к приёму невозможно после 24 часов с момента приёма.
- Удаление графика невозможно, если он используется сотрудниками.

## Интерфейс приложения

Приложение реализовано на **WinForms** и включает следующие формы:

### Стартовая форма
Авторизация по роли и паролю (выпадающий список ролей).

### Главные меню по ролям
Каждая роль имеет собственную навигационную форму с набором кнопок для перехода к функциональным разделам.

### Функциональные формы
- **Клиенты** — таблица, поиск, сортировка, добавление/обновление.
- **Сотрудники** — таблица, фильтр, добавление/обновление.
- **График** — работа с расписанием сотрудников.
- **Услуги** — справочник услуг.
- **Питомцы** — база пациентов клиники.
- **Приём** — управление приёмами и услугами.
- **Медикамент** — справочник медикаментов.
- **СкладскиеОперации** — журнал складских операций.

Все формы используют компоненты `DataGridView`, `ComboBox`, `DateTimePicker`, `NumericUpDown` и обеспечивают валидацию ввода.

## Требования к запуску

### База данных
- Microsoft SQL Server 2019 или новее.
- SQL Server Management Studio.
- Выполнить скрипты из директории `Database/` в указанном порядке.

### Приложение
- ОС: Windows 10/11.
- .NET Framework 4.7.2 или новее.
- Visual Studio 2019+.
- Настроить строку подключения к SQL Server в файле `App.config`.

---

## Сборка и запуск

1. Клонировать репозиторий:

```bash
git clone <URL_репозитория>
cd VetClinic
```

2. Развернуть базу данных:
   - Открыть SQL Server Management Studio.
   - Выполнить скрипт `create_tables.sql` для создания структуры.
   - Выполнить `views.sql` и `procedures.sql` для создания представлений и процедур.
   - Выполнить `insert_data.sql` для начального наполнения.

3. Открыть решение `VetClinic.sln` в Visual Studio.

4. Восстановить NuGet-пакеты (при необходимости).

5. Настроить строку подключения в `App.config`:
   ```xml
   <connectionStrings>
     <add name="VetClinicDB" 
          connectionString="Data Source=.;Initial Catalog=Ветеринарная_клиника;Integrated Security=True"
          providerName="System.Data.SqlClient" />
   </connectionStrings>
   ```

6. Собрать проект (`Ctrl+Shift+B`) и запустить (`F5`).
